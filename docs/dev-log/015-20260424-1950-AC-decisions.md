## 决策 1：AC 15.7 hotfix 批准

**问题**：`quotaManager._computeTier()` 阈值反序约束缺失。当 greenThreshold < yellowThreshold 或 yellowThreshold < orangeThreshold 时，tier 判定逻辑失效。

**裁定**：创建 `hotfix/ac15.7-tier-threshold-order` 任务，排队等 T008 merge 后 spawn。

**影响范围**：
- `app/utils/quotaManager.js`：_computeTier() 方法增加前置约束检查
- `app/preferences-renderer.js`：绑定时验证用户输入的阈值顺序
- `test/quotaManager.js`：新增约束检查测试用例

**优先级**：Medium（影响 quota tier 判定正确性，但当前默认值安全，仅在用户自定义阈值时触发）

## 决策 2：v1.22 backlog — soft-reminder-renderer 硬编码阈值

**问题**：`soft-reminder-renderer.getTierClass()` 中 tier 界限（70%/30%/10%）硬编码，不跟随 settings 中的 greenThreshold / yellowThreshold / orangeThreshold。

**裁定**：判定为已知限制，v1.22 不修复，列入 v1.23+ backlog。

**理由**：
- 当前版本默认阈值与硬编码值一致，用户感知无差
- 修复需跨 IPC 传递 settings 阈值到 soft-reminder-renderer，工程复杂度中等
- 优先级低于 T008/T010 feature completion

**后续追踪**：在 v1.23 planning 时重新评估。

## 里程碑
