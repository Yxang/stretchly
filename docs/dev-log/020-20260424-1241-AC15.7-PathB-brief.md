## AC 原文引用

**出处**：`ACCEPTANCE.md:456-457`

```
定义：当用户自定义的 quotas 阈值反序时（greenThreshold ≥ yellowThreshold 或 yellowThreshold ≥ orangeThreshold），
期望行为是**公式连锁下调保留用户 Yellow**，即：
  1. 保持 yellowThreshold 用户值
  2. 根据用户 orangeThreshold vs yellowThreshold 大小关系，级联下调 orangeThreshold 和 redThreshold
  3. 保留用户意图（黄档仍为约束点）
```

## 实现策略（Path B 正式版）

**Title**: quotaManager._computeTier() — 反序约束下的级联调整

**公式**：

```javascript
// 给定用户输入：greenThreshold (G), yellowThreshold (Y), orangeThreshold (O)
// 目标：G > Y > O > 0 严格递减

// Step 1: 确保 Y < G（保持 Yellow 约束）
if (Y >= G) {
  Y_corrected = G - 1;  // 保持用户黄档意图，下调 Yellow
} else {
  Y_corrected = Y;
}

// Step 2: 级联调整 O 和 R（与 Y_corrected 保持递减）
if (O >= Y_corrected) {
  O_corrected = Y_corrected - 1;  // 下调橙档
  R_corrected = O_corrected - 1;   // 下调红档
} else {
  O_corrected = O;
  R_corrected = O - 1;
}

// 结果：(G, Y_corrected, O_corrected, R_corrected) 严格递减
```
