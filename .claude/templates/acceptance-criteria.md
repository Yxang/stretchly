## 6. QA 分工方案

根据验收标准的数量和复杂度，评估需要多少个产品 QA 并行验证。

**QA 数量**：按工作量分配，每个 QA 负责 5-8 条 AC。4+ 个 QA 时分批启动（每批 2-3 个，前批无阻塞后再开下批）；**Playwright QA 每批最多 2 个**（硬约束）。

**Layer 汇总**：

| Layer | 条数 | Tool | 说明 |
|-------|------|------|------|
| L1 | [N] | 静态 | 文件审查 / grep，可选 Haiku |
| L2 | [N] | 静态 | CLI/API，Sonnet |
| L3 | [N] | Playwright / Maestro / Appium | playwright-cli skill，Opus |
| L4 | [N] | — | 不启动 QA agent，用户手动验证 |

**分工**（多 QA 时填写）：

| QA 编号 | 负责的功能/标准 | Layer 范围 | Tool | 探索测试重点 |
|---------|---------------|-----------|------|-------------|
| product-qa-1 | [如："功能 1-3 + 非功能性需求"] | [L1/L2/L3] | [Playwright] | [如："正常流程、性能"] |
| product-qa-2 | [如："功能 4-6 + 边界情况"] | [L2/L3] | [Playwright] | [如："异常输入、错误恢复"] |

**批次声明示例**（4+ QA 时填写）：

```
Batch 1: product-qa-1 [Playwright], product-qa-2 [Playwright]
Batch 2: product-qa-3 [Maestro], product-qa-4 [静态]
（⚠️ 使用 Playwright 的 QA 同时活跃数 ≤2，与总 QA 数无关）
```

> 原则：每个 QA 的验收范围不重叠，探索测试范围可重叠。分工粒度以「功能」为单位，不拆分单个功能的标准。L4 条目不分配给 QA agent，由用户按人工验证手册自行验收。

## 8. 健康评分配置

*由 Product Lead 在版本启动前填写；产品 QA 在验收时按此配置评分。*

### 8.1 默认权重表

| 维度 | 默认权重 | 说明 |
|------|---------|------|
| 功能正确性 | 25% | 核心功能是否按预期工作 |
| 用户体验 | 15% | 交互流程是否顺畅、符合直觉 |
| 视觉质量 | 15% | 界面是否美观、一致、无视觉缺陷 |
| 错误处理 | 12% | 异常情况是否有友好提示和合理恢复 |
| 边界情况 | 10% | 极端输入/状态下是否稳定 |
| 性能感知 | 8% | 响应速度是否满足用户预期 |
| 内容质量 | 8% | 文案、标签、提示信息是否准确清晰 |
| 可访问性 | 7% | 是否支持屏幕阅读器、键盘操作、色彩对比度等 |
| **合计** | **100%** | |

### 8.2 评分标准

| 评级 | 分数区间 | 含义 | 处理方式 |
|------|---------|------|---------|
| 健康 | ≥ 80 | 功能整体质量良好，可交付 | 正常推进 |
| 需关注 | 60 – 79 | 存在明显缺陷，需评估是否阻塞交付 | Product Lead 决定是否阻塞 |
| 需修复 | < 60 | 质量不达标，建议返工 | 建议打回开发，Product Lead 决定是否合并 |

### 8.3 本版本权重配置

*Product Lead 按项目类型调整。不适用的维度权重设为 0，其余维度权重之和须重新归一化到 100%。*

| 维度 | 本版本权重 | 调整原因（如有变化） |
|------|-----------|------------------|
| 功能正确性 | 25% | |
| 用户体验 | 15% | |
| 视觉质量 | 15% | |
| 错误处理 | 12% | |
| 边界情况 | 10% | |
| 性能感知 | 8% | |
| 内容质量 | 8% | |
| 可访问性 | 7% | |
| **合计** | **100%** | |

**权重调整指引**：
- CLI 工具 / API 项目：建议将「视觉质量」设为 0，将「功能正确性」提升至 35%，「错误处理」提升至 18%
- 内容型产品：建议将「内容质量」提升至 15%，「视觉质量」降至 10%
- 调整后各维度权重之和必须等于 100%；设为 0 的维度在评分表中标注「不适用」
